# Archive

Files preserved for reproducibility and provenance.

## Files

- **cot_analyze_all.py** — 5-model analysis script. Computed `../../results/archive/full_analysis.json` from buggy synthetic-skeleton Phase 3 data. - **redundant_dupes/** — Three JSONs that are exact md5-duplicates of files in `../../results/`. Originally in `experiment/results/` (an orphan duplicate directory). Preserved separately so the duplication is visible.
